01 / ABOUT

STUDENT / INDEPENDENT DEVELOPER

CURIOUS BY NATURE. BUILDER BY CHOICE.

I'm a student and independent web developer. I learn by building — taking an idea, working out how it should behave, and turning it into a website that people can actually use.

Most of my work starts with a simple question: what is this website for, and who is it for? From there I plan the structure, design the layout in the browser, and build it with semantic HTML, modern CSS and plain JavaScript.

I'm especially interested in how small businesses use the web — how a clear service page, a sensible enquiry path and a fast mobile experience can be more useful than a complicated site. Every project I take on is a chance to get better at that craft.

PROJECT 01 / CASE STUDY

GLOW STUDIO

OVERVIEW

Glow Studio is a fictional premium salon website built as a self-initiated demonstration. The goal was to design and build a complete, multi-section site from scratch — not a single landing page — and to practise the full path from structure to responsive frontend.

DESIGN APPROACH

The visual direction is calm and editorial: a warm neutral palette, a serif display face for headlines, generous whitespace and restrained motion. Content is grouped by intent — who the salon is, what it offers, visual proof, then a single clear enquiry path. Layouts were designed mobile-first and expanded upward, so the small screen is a deliberate composition rather than a compressed desktop.

TECHNOLOGIES

  • HTML5
  • CSS3
  • JAVASCRIPT
  • GITHUB PAGES

FEATURES

  • Sticky navigation with a mobile menu
  • Service cards with individual enquiry actions
  • Editorial gallery section for visual work
  • Appointment enquiry interface with a clear demo notice
  • Responsive layouts across mobile, tablet and desktop
  • Scroll-based reveals and hover states

LIMITATIONS

  • Demonstration only — the salon is fictional
  • No backend: the enquiry form does not send or store data
  • Contact details and social links are placeholders
  • Imagery is represented by designed placeholders
  • No booking system, payments or accounts

SELF-INITIATED DEMONSTRATION — NOT A CLIENT PROJECT.

03 / PROCESS

FIVE STAGES / ONE CLEAR PATH

FROM PROBLEM TO DIGITAL PRODUCT.

A small, repeatable process. Each stage ends with something concrete, so decisions are made before they become expensive to change.

NO ESTIMATES PROMISED BEFORE SCOPE IS AGREED.

  1. 01

    DISCOVER

    Understand the business, the audience and the actual problem the website needs to solve — in plain language.

    OUTPUT / WRITTEN BRIEF

  2. 02

    PLAN

    Define the website structure, the pages that are genuinely needed and the requirements for each one.

    OUTPUT / SITEMAP & SCOPE

  3. 03

    DESIGN

    Create the layout, visual identity and user experience — typography, grid, colour and hierarchy.

    OUTPUT / DESIGN IN THE BROWSER

  4. 04

    BUILD

    Develop the responsive frontend with semantic HTML, modern CSS and JavaScript — component by component, section by section.

    OUTPUT / WORKING PAGES

  5. 05

    TEST

    Check usability, responsiveness, functionality and quality — on real viewport sizes, with the keyboard, not just the mouse.

    OUTPUT / FIXES & REVIEW
